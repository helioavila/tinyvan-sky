# tinyvan-sky

Pixel-art visualizer of Vancouver's SkyTrain (Expo Line) — web prototype first, ESP32-S3 AMOLED desk device later.

See **HANDOFF.md** for the full spec. To start in Claude Code:

> Leia o HANDOFF.md, entre em plan mode e proponha o plano da Fase 0 + Fase 1 antes de codar.

Put TransLink's static GTFS (`google_transit.zip`) in `data/raw/`.
